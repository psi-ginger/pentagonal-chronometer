# 🕰️ The Pentagonal Chronometer

> *"Why does a clock face have to be round?"*  
> A defiant, standalone frontend artifact breaking conventional timekeeping rules. Built with zero dependencies, raw Web Audio synthesis, and real-time seismic feedback.

---

## ⚡ Key Features

* **Subversive Geometry**: 5-sided (pentagonal) procedural SVG bezel & dial.
* **4-Hand Mechanism**: Standard Hour, Minute, and Second hands — plus a **4th Anomaly Hand** tracking unpredictable states.
* **Synthesized Audio (Zero MP3s)**: Mechanical escapement tick-tock and emergency siren synthesized entirely in real-time via the browser's native **Web Audio API**.
* **Physical Feedback**: Seismic tremor viewport shockwave (±14px screen shake) with a dark-red containment alert mode.
* **Pure Single-File**: 100% self-contained in a single HTML file (~21KB). No build steps, no npm, no external CDNs.

---

## 🧠 Behind the Build: The "Underdog" Engine

This project was built to test whether a lightweight, cost-effective AI model could produce expressive, out-of-the-box frontend engineering through natural human-AI collaboration.

* **Engine**: `Gemini 3.8 Flash (Low)` (Low token cost, low compute footprint)
* **Approach**: Natural human-AI pair-programming using short colloquial Thai dialogue.
* **Zero Prompt Engineering**: No massive 2,000-word prompt templates. Just direct intent, instant bug spotting, and iterative craftsman feedback.

*(See [DESIGN_LOG.md](DESIGN_LOG.md) for the actual human-AI dialogue transcript.)*
